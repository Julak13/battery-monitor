How your device updates

1. Device readsfirmware.json
2. Compares againstits own version
3. If differentoffers to install
4. Downloads intothe spare flash slot
5. Thenreboots into it

Open the dashboard, go to System → Firmware update and press Check for updates. The old firmware stays in the other slot until the new one has been written completely, so a failed download cannot brick the board.

Publishing a new version

  1. Build the binary: 
    arduino-cli compile --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs \
  --output-dir build BatteryMonitor
  2. Rename build/BatteryMonitor.ino.bin to BatteryMonitor-<version>.bin.
  3. Copy it into this folder, beside firmware.json.
  4. Edit firmware.json: set version to match FW_VERSION in config.h, point url at the new file, and write a short notes line.
  5. Commit and push. GitHub Pages republishes in about a minute.

The version string must match FW_VERSION exactly. The device compares them as plain text, so 1.0.4 and v1.0.4 are different and it would offer the update again after installing.

Monitoring instrument only — not a battery protection device.
