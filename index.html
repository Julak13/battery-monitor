Battery Monitor Installer

Install the firmware straight from this page. No Arduino software, no command line.

Install v1.0.3

This browser cannot talk to USB devices. Open this page in Google Chrome or Microsoft Edge on a computer. This page must be opened over https:// to install.

Before you start

ComputerWindows, Mac or Linux
BrowserChrome or Edge
CableUSB data cable
TimeAbout one minute

A phone will not work, and neither will Safari or Firefox — only Chrome and Edge can reach a USB port from a web page. Some charging cables carry power but no data; if the board never appears in the list, try a different cable.

Steps

  1. Plug the battery monitor into the computer with the USB cable.
  2. Press Connect & install above.
  3. A small window lists the serial ports. Pick the one that appears when you plug the board in — usually named CP210x, CH340 or USB Serial.
  4. Press Install and wait. Do not unplug it.
  5. When it finishes, the board restarts on its own.

Your settings are kept

This does not erase your calibration. The voltage calibration, alarm settings and the lifetime energy totals are stored in a separate area of memory that the installer leaves alone. If a prompt ever offers to erase the device, say no — erasing means re-doing the calibration with a multimeter.

After this first install

You only need the cable once. From then on the monitor updates itself over Wi-Fi: open its dashboard, go to System → Firmware update and press Check for updates. It reads firmware.json from this same site and installs anything newer by itself.

If it will not connect

No ports listed: the USB-to-serial driver is missing. Install the CP210x or CH340 driver, then unplug and plug the board back in.

Fails part-way: hold the BOOT button on the board, press Install, and release BOOT once it starts writing.

Still stuck: try a different USB cable before anything else. It is the most common cause by a wide margin.

Monitoring instrument only — not a battery protection device.
